
Student Feedback Analysis Dashboard

 📌 Project Overview

The Student Feedback Analysis Dashboard is an interactive Power BI dashboard developed to analyze student feedback and trainer performance.

The dashboard provides an overview of feedback responses, trainer ratings, courses, and rating distribution. Interactive filters allow users to analyze feedback based on trainer, course, slot, year, batch, and date.

 🛠️ Tools & Technologies Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Cleaning
- Data Visualization

📊 Dashboard Overview

The dashboard provides insights into:

- Total number of feedback responses
- Total number of trainers
- Total number of courses
- Trainer-wise rating counts
- Percentage distribution of ratings
- Trainer performance analysis
- Course-wise analysis
- Feedback analysis by slot, year, batch, and date

🔄 Project Workflow

1. Collected student feedback data.
2. Cleaned and prepared the data using Microsoft Excel.
3. Imported the cleaned data into Power BI.
4. Transformed and prepared the data using Power Query.
5. Created calculated measures using DAX.
6. Designed interactive KPI cards and charts.
7. Added slicers for Trainer, Course, Slot, Year, Batch, and Date.
8. Created the final interactive Feedback Analytics Dashboard.
